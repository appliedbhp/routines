Open .abhp files by double-clicking

Install Routines using Chrome or Edge on a desktop computer or Chromebook. Use the browser’s Install app option, then allow Routines to open .abhp files when prompted.

  1. Mac: select an .abhp file in Finder → Get Info → Open with → Routines → Change All.
  2. Windows: right-click an .abhp file → Open with → Choose another app → Routines, then choose Always.
  3. Chromebook: select the file in Files and choose Routines from Open with; set it as the default if offered.

Routines reads the file type and opens the matching tool. Supported systems use the Routines icon. An existing installation may need to be reopened or reinstalled to refresh its file icon. Safari, Firefox, and mobile devices may not support this file association; use drag and drop or Choose a file instead.
