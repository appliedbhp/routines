October 8, 2026

Take your tools offline

Prepare your visuals before heading into a classroom, traveling, or working somewhere without Wi-Fi.

  • Available offline: open the site online once and wait for this indicator before disconnecting.
  • Download this board for offline use: keep a separate copy on this device with its pictures, then return to it using Open offline copy. Download again after making changes.
  • Keep working: create and edit visuals, run timers and sessions, save locally, import/export files, and print without internet.
  • Install the app: use your browser’s Install app option on Chromebook, or Safari → Share → Add to Home Screen on iPad.

Cloud accounts and new picture searches still need internet. Some fonts may use a fallback. If a picture cannot download, the site shows a warning. Export important boards as backups because clearing browser storage removes offline copies.
